# About
Code for "A nonlinear inhibition pathway underlying cortical responses to tuned holographic optogenetic perturbations"

# To reproduce figures...
1. Navigate to the directory `core` and follow the instructions under the "Setup" section in `core/README.md`.
2. In the directory containing this file, run
```
pip install -r requirements.txt
```
3. Navigate to the directory `paper` and follow the instructions in `paper/README.md`.
